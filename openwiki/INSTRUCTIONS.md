# OpenWiki 写入约束

1. `docs/` 是人工叙事层，只读；不得创建、修改、删除或重写其中任何文件。
2. `openwiki/` 是代码快照层，只写代码能够证明的架构、模块、API、数据流和验证信息。
3. 已有使用说明、运行手册、决策和踩坑只做相对链接，不重复生成。
4. 人工临时计划目录是严格禁区：不得读取、总结、引用，也不得从文件名推断内容；生成页面不得出现该目录的路径或名称。
5. 遵守 `.openwikiignore`；不得记录秘密值、个人信息、缓存或大文件内容。
6. 增量更新只修改 OpenWiki 自己拥有的内容；不改业务源码、测试、README 或 AGENTS.md 的人工区。
7. V2 只允许本机手动运行 OpenWiki；不得生成、描述或建议 GitHub Actions、CI、LaunchAgent 或其他定时任务。
8. 根目录 Agent 入口只允许 OpenWiki 修改自己的标记区；该区域必须说明当前为本机手动更新，不得宣称已启用自动更新。
9. `_skeleton.md` 等内部规划产物不是百科正文，不得保留或加入索引。
10. 增量更新必须保留仍被当前源码和测试证明的既有事实；不得为了缩短页面而删除仍然成立的安全边界、排除规则或验证约束。
11. 本次代码变化涉及的行为和对应回归测试必须反映在最相关页面中；若行为未变化，不得无关重写其他段落。
12. 以下由源码和测试固定的关键事实不得在增量更新中省略：工作草稿生命周期检查、临时目录不参与扫描、临时计划与虚构工作流声明会被拒绝；`ensure_symlink()` 对受管绝对链接同时校验解析位置和存储文本，大小写或别名路径即使指向同一位置也必须规范化，回归测试为 `test_link_normalizes_absolute_symlink_target`。
