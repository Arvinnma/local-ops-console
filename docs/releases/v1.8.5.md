# Local Ops 1.8.5

[简体中文](#简体中文) · [English](#english)

## 简体中文

Local Ops 1.8.5 修复 Caddy 内部端口与 macOS 无端口转发规则不同步时，所有 `.localhost` 入口不可用并连带误报 SSH 隧道失败的问题。

### 主要更新

- 在“设置 → 运行设置”中新增可编辑的 Caddy 内部端口。
- 修改端口前检查数值范围、Local Ops 内部端口冲突和本机监听占用。
- PF anchor 不再写死 `19080`，启用或修复无端口访问时按当前 Caddy 端口动态生成 IPv4/IPv6 规则。
- 无端口规则与 Caddy 不一致时明确显示“需要修复”，不再把域名入口失败混同为 SSH 进程失联。
- Caddy 配置生成或热加载失败时自动恢复旧配置。

### 安装与升级

下载 `Local-Ops-1.8.5-arm64.dmg`，打开后把 **Local Ops** 拖到“应用程序”。本版本仅支持 Apple Silicon，暂不提供 Intel 安装包。

升级会保留 `catalog.json`、`last-session.json`、本机 API 密钥和钥匙串项目。替换 App 会重载内置后台，重要传输结束后再升级。

### 验证

- 语法检查和 90 项单元测试；
- Caddy 端口范围、内部冲突、监听占用和 PF 模板回归；
- 中英文文案、钥匙串、安装版 API、浏览器和 SSH 状态回归；
- arm64 架构、深层签名、DMG 挂载布局与制品内容检查。

## English

Local Ops 1.8.5 fixes a mismatch between the configured Caddy internal port and the privileged macOS portless forwarding rule that could make every `.localhost` entry unavailable and surface false SSH-tunnel failures.

### Highlights

- Add an editable Caddy internal port under **Settings → Runtime Settings**.
- Validate the port range, Local Ops internal-port collisions, and existing loopback listeners before applying a change.
- Generate IPv4 and IPv6 PF anchor rules from the selected Caddy port instead of hard-coding `19080`.
- Report a Caddy/PF mismatch as **Repair Portless Access** instead of conflating a domain-entry failure with a lost SSH process.
- Restore the prior catalog automatically when Caddy configuration rendering or hot reload fails.

### Install and upgrade

Download `Local-Ops-1.8.5-arm64.dmg`, open it, and drag **Local Ops** to **Applications**. This release supports Apple Silicon only; Intel packages are not provided.

Upgrades preserve `catalog.json`, `last-session.json`, the local API token, and Keychain items. Replacing the App reloads the bundled backend, so finish important transfers before upgrading.

- bilingual copy, Keychain, installed API, browser, and SSH-state regressions;
- arm64 architecture, deep signature, mounted-DMG layout, and artifact-content checks.
