# Local Ops 1.8.3

[简体中文](#简体中文) · [English](#english)

## 简体中文

Local Ops 1.8.3 集中修复托管服务与 SSH 隧道的长期运行可靠性，并把 v1.8.2 之后经过本机验收的同步、ProxyJump 和健康检查改进正式打入安装包。

### 主要更新

- 新增托管服务监督器：Process Compose 短暂丢失状态时，以真实子进程 PID 对账，避免仍在运行的 Dashboard 被重复启动。
- 启动前检查配置的本机健康端口；端口已被其他进程占用时显示降级并阻止重复实例，不再形成每两秒一次的无限重启风暴。
- 停止和重启托管服务时清理完整进程树；无健康地址的服务继续使用原有直接生命周期。
- SSH/TCP 存活与 HTTP 应用就绪彻底分离，应用 `5xx`、连接失败或超时不会杀死健康隧道。
- 隧道和完整域名入口 HTTP 超时提高到 10 秒；受认证保护的完整入口返回 `401/403` 时视为已到达应用。
- 域名入口终态失败后每 30 秒低频恢复探测，恢复后无需重启 SSH 即可重新显示已连接。
- 支持由 OpenSSH 管理 `ProxyJump` / `ProxyCommand` 链路，主控制台会自动同步其他客户端新增或编辑的资源。
- 保留期望运行状态和启停审计，避免会话捕获撞上编排器短暂重启时丢失应恢复的资源。

### 安装与升级

下载 `Local-Ops-1.8.3-arm64.dmg`，打开后把 **Local Ops** 拖到“应用程序”。本版本仅支持 Apple Silicon，暂不提供 Intel 安装包。

社区包使用 ad-hoc 签名，尚未经过 Apple 公证。如果 Gatekeeper 首次拦截，请按住 Control 点击 App，选择“打开”并确认。

升级会保留 `catalog.json`、`last-session.json`、本机 API 密钥和钥匙串项目。替换 App 后首次启动会更新内置后台，可能重启 Process Compose Worker 下的服务和 SSH 隧道；请先结束正在进行的数据传输，并在升级后复核必要监听端口。

## English

Local Ops 1.8.3 focuses on long-running managed-service and SSH-tunnel reliability, and packages the synchronization, ProxyJump, and readiness fixes accepted after v1.8.2.

### Highlights

- Add a managed-service supervisor that reconciles the real child PID when Process Compose briefly loses state, preventing a surviving dashboard from being launched again.
- Check the configured loopback health port before launch. A port owned by another process becomes a stable degraded state and blocks duplicates instead of creating a two-second restart storm.
- Stop and restart the complete managed process tree; services without a health URL retain their existing direct lifecycle.
- Fully separate SSH/TCP liveness from HTTP application readiness, so `5xx`, connection failures, and timeouts never kill a healthy tunnel.
- Increase tunnel and complete-domain HTTP timeouts to ten seconds and accept `401/403` as proof that an authentication-protected complete entry reached the application.
- Probe terminal domain failures once every 30 seconds and recover without restarting SSH.
- Let OpenSSH own `ProxyJump` / `ProxyCommand` reachability and keep the main console synchronized with resources changed by another client.
- Preserve desired-running state and start/stop audit data across short orchestrator restart windows.

### Install and upgrade

Download `Local-Ops-1.8.3-arm64.dmg`, open it, and drag **Local Ops** to **Applications**. This release supports Apple Silicon only; Intel packages are not provided.

The community build is ad-hoc signed and not Apple-notarized. If Gatekeeper blocks the first launch, Control-click the app, choose **Open**, and confirm.

Upgrades preserve `catalog.json`, `last-session.json`, the local API token, and Keychain items. The first launch after replacement updates the bundled backend and may restart services and SSH tunnels managed by the Process Compose worker. Finish active transfers first and verify required listeners afterward.

- secret scans of Git history and the complete working tree;

- DMG checksum, mounted layout, version, and packaged lifecycle-file verification.
