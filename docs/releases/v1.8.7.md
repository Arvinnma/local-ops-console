# Local Ops 1.8.7

[简体中文](#简体中文) · [English](#english)

## 简体中文

Local Ops 1.8.7 修复菜单栏与主控制台的刷新体验，明确区分 SSH 转发、应用就绪和域名入口状态，并为 macOS 无端口访问增加有边界的自动恢复。

### 主要更新

- 后台轮询不再周期性冻结菜单栏或网页按钮；刷新期间继续展示并使用最后一次成功快照，只有快照真实过期或控制面离线时才禁用写操作。
- 避免整页重绘造成的闪烁，普通刷新、强制刷新和操作后的刷新保持串行和原子应用。
- SSH 转发已经建立但应用健康检查或完整域名入口尚未就绪时，分别显示“服务未就绪”或“入口未就绪”，并保留明确的停止操作，不再长期误显示为不可操作的“连接中”。
- macOS PF 被关闭或主规则丢失时，仅在 Caddy 内部端口健康、无端口入口失败且配置已启用无端口访问的条件下触发恢复。
- PF 恢复严格按 Apple 主规则、显式修复请求、Local Ops 子 anchor 的顺序执行，并使用单飞、冷却和持久化预算防止频繁重载。
- 特权 Helper 改为请求驱动，不再依赖一次性的 `RunAtLoad`；健康的 80 端口不会触发修复。

### 安装与升级

下载 `Local-Ops-1.8.7-arm64.dmg`，打开后把 **Local Ops** 拖到“应用程序”。本版本仅支持 Apple Silicon，暂不提供 Intel 安装包。

升级保留 `catalog.json`、`last-session.json`、本机 API 密钥和钥匙串项目。当前替换内置后台会重启 Local Ops 控制面和 Process Compose Worker，并重新建立记忆会话中的 SSH 隧道；请先结束重要数据传输。

## English

Local Ops 1.8.7 improves menu-bar and console refresh behavior, separates SSH forwarding from application and domain-entry readiness, and adds bounded recovery for macOS portless access.

### Highlights

- Background polling no longer freezes menu-bar or browser controls. The last successful snapshot remains usable during refresh; mutations are disabled only when data is actually stale or the control plane is offline.
- Avoid full-view flicker while keeping ordinary, forced, and post-mutation refreshes serialized and atomically applied.
- Report **Service Not Ready** or **Entry Not Ready** when the SSH forward is alive but application or complete-domain readiness has not passed, while retaining an explicit Stop action instead of an indefinitely disabled **Connecting** state.
- Recover macOS PF only when the configured Caddy port is healthy, the portless entry is unavailable, and portless access is enabled.
- Restore PF in Apple-main-rules, explicit-request, Local-Ops-child-anchor order, guarded by single-flight execution, cooldown, and a persistent attempt budget.
- Make the privileged helper request-driven instead of relying on one-shot `RunAtLoad`; a healthy port 80 entry does not trigger repair.

### Install and upgrade

Download `Local-Ops-1.8.7-arm64.dmg`, open it, and drag **Local Ops** to **Applications**. This release supports Apple Silicon only; Intel packages are not provided.

Upgrades preserve `catalog.json`, `last-session.json`, the local API token, and Keychain items. Replacing the bundled backend currently restarts the Local Ops control plane and Process Compose worker, then re-establishes remembered SSH tunnels. Finish important transfers first.
