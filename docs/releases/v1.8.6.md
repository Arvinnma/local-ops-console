# Local Ops 1.8.6

[简体中文](#简体中文) · [English](#english)

## 简体中文

Local Ops 1.8.6 集中修复两类长期运行问题：界面刷新乱序，以及 SSH 隧道在数小时前已经恢复后仍沿用旧的累计重启次数。

### 主要更新

- 主控制台与菜单栏改用同一份原子快照，普通轮询和强制刷新串行执行，较慢的旧响应不会覆盖新状态。
- 控制面短暂离线时保留最后一次成功快照并明确标记为旧数据，所有写操作在恢复前禁用。
- 浏览器与菜单栏使用相同的 SSH 四态动作契约；连接中不可误停，终态失败显示重试。
- 每条 SSH 隧道独立记录连续失败次数，最多 10 次，重试间隔仍为约 3 秒。
- 只有 SSH 转发、本地回环监听、可选 HTTP 健康检查和 10 秒稳定窗口全部通过后，连续失败次数才清零。
- 稳定连接后再次断线会从第 1 次重新计算，不再沿用数小时前已经恢复的历史失败次数。
- UI 显示当前连续失败次数；配置上限只作为说明，不再与实际已使用次数混淆。

### 安装与升级

下载 `Local-Ops-1.8.6-arm64.dmg`，打开后把 **Local Ops** 拖到“应用程序”。本版本仅支持 Apple Silicon，暂不提供 Intel 安装包。

升级会保留 `catalog.json`、`last-session.json`、本机 API 密钥和钥匙串项目。替换 App 会重载内置后台，并可能重新建立托管 SSH 隧道；重要传输结束后再升级。

### 验证

- 语法、版本一致性与 135 项单元/回归测试；
- 连续失败 9/10 边界、稳定窗口归零、再次断线从 1 开始、多隧道独立计数和监督器重启恢复；
- 原子刷新、旧快照保护、菜单栏健康去抖和 SSH 动作一致性；
- 原生钥匙串、隔离刷新、安装包签名、arm64 架构和 DMG 布局检查。

## English

Local Ops 1.8.6 fixes two long-running reliability problems: out-of-order UI refreshes and SSH tunnels retaining failures from an outage that had already recovered hours earlier.

### Highlights

- Apply one atomic snapshot in the browser console and menu-bar panel, serializing ordinary and forced refreshes so a slower old response cannot overwrite newer state.
- Preserve the last successful snapshot during a temporary control-plane outage, clearly mark it stale, and disable mutations until recovery.
- Use the same four-state SSH action contract in the browser and menu bar; connecting rows cannot be stopped accidentally and terminal failures expose Retry.
- Track up to 10 consecutive failures independently for every SSH tunnel while retaining the existing three-second retry cadence.
- Reset the counter only after the SSH forward, loopback listener, optional HTTP readiness check, and a ten-second stability window all succeed.
- Start a later outage at failure 1 after a stable connection instead of inheriting failures from hours earlier.
- Display the current consecutive-failure count separately from the configured retry ceiling.

### Install and upgrade

Download `Local-Ops-1.8.6-arm64.dmg`, open it, and drag **Local Ops** to **Applications**. This release supports Apple Silicon only; Intel packages are not provided.

Upgrades preserve `catalog.json`, `last-session.json`, the local API token, and Keychain items. Replacing the App reloads the bundled backend and may re-establish managed SSH tunnels, so finish important transfers before upgrading.

### Verification

- Syntax, version-consistency, and 135 unit/regression tests;
- failure 9/10 boundaries, stable-window reset, later outage restarting at 1, per-tunnel isolation, and supervisor-restart recovery;
- atomic refresh, stale-snapshot protection, menu-bar health debounce, and SSH action parity;
- native Keychain, isolated refresh, app signature, arm64 architecture, and mounted-DMG layout checks.
