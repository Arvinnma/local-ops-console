# Local Ops 1.8.4

[简体中文](#简体中文) · [English](#english)

## 简体中文

Local Ops 1.8.4 修复菜单栏可能把长期运行的 SSH 隧道误判成用户主动停止，并把错误状态固化到下一次会话恢复的问题。

### 主要更新

- 菜单栏停止服务或 SSH 隧道前必须经过真实用户点击和明确确认。
- 控制 API 拒绝未经确认的菜单栏隧道停止请求，不再把它记录成用户主动停止。
- 生命周期审计新增事件名、动作 ID、调用路径和用户确认结果，后续可以准确追踪停止来源。
- 会话捕获遇到未经确认的菜单栏停止时，继续保留此前已记忆的长期隧道，不会把异常短暂离线固化成下次不恢复。
- 原有 SSH 快速失败、有限重试、HTTP readiness、完整域名入口检查和托管服务进程对账逻辑保持不变。

### 安装与升级

下载 `Local-Ops-1.8.4-arm64.dmg`，打开后把 **Local Ops** 拖到“应用程序”。本版本仅支持 Apple Silicon，暂不提供 Intel 安装包。

社区包使用 ad-hoc 签名，尚未经过 Apple 公证。如果 Gatekeeper 首次拦截，请按住 Control 点击 App，选择“打开”并确认。

升级会保留 `catalog.json`、`last-session.json`、本机 API 密钥和钥匙串项目。替换 App 前请结束重要传输，并在升级后复核必要服务与 SSH 监听。

## English

Local Ops 1.8.4 fixes a menu-bar lifecycle bug that could treat long-running SSH tunnels as deliberately stopped and persist that accidental state into the next session restore.

### Highlights

- Require a trusted user click and an explicit confirmation before the menu bar stops a service or SSH tunnel.
- Reject unconfirmed menu-bar tunnel stops in the control API instead of recording them as deliberate user actions.
- Add the event name, action ID, call path, and confirmed intent to lifecycle audit records.
- Preserve a previously remembered long-running tunnel when session capture sees an unconfirmed menu-bar stop, so a transient incident cannot become the next-launch baseline.
- Keep the existing SSH fast-failure, bounded-retry, HTTP-readiness, complete-domain, and managed-service reconciliation behavior unchanged.

### Install and upgrade

Download `Local-Ops-1.8.4-arm64.dmg`, open it, and drag **Local Ops** to **Applications**. This release supports Apple Silicon only; Intel packages are not provided.

The community build is ad-hoc signed and not Apple-notarized. If Gatekeeper blocks the first launch, Control-click the app, choose **Open**, and confirm.

Upgrades preserve `catalog.json`, `last-session.json`, the local API token, and Keychain items. Finish important transfers before replacement and verify required services and SSH listeners afterward.

### Verification

- Syntax checks and 86 unit tests;
- trusted/untrusted menu-bar clicks, stop confirmation, API rejection, and session-preservation regressions;
- root and desktop dependency audits;
- macOS Keychain / AskPass integration with an encrypted Ed25519 key;
- installed API, service, SSH, Caddy, and browser regressions;
- arm64 architecture, deep signature, mounted-DMG layout, and artifact-content checks.
