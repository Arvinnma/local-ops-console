# Local Ops 1.7.0

Local Ops 1.7.0 expands the app from a local process dashboard into a portable, bilingual operations console.

## What's new

- Click **Needs Attention** to inspect every stopped, unhealthy, or offline resource and jump to its page.
- Switch between Simplified Chinese and English from Settings.
- Export or import services, SSH tunnels, monitored services, reverse proxies, terminal actions, language, and non-Docker startup preferences.
- Control local Docker containers and optionally launch Docker Desktop before starting stopped containers.
- Save Terminal.app or iTerm2 commands and SSH sessions.
- Edit and drag-reorder user-managed resources with optimistic UI updates.
- Use consistent primary-action and overflow-menu controls throughout the app.
- Install with a self-contained Apple Silicon DMG that bundles Caddy and Process Compose.

## Install

Download `Local-Ops-1.7.0-arm64.dmg`, open it, and drag **Local Ops** to **Applications**. Existing Local Ops configuration is preserved during upgrades.

This build uses an ad-hoc local signature and is not Apple-notarized. If required on first launch, use **Control-click → Open**.

## Security and migration

Configuration exports never contain Docker state, API tokens, SSH private-key contents, system port-forwarding rules, or administrator authorization. Review the imported file before applying it on another Mac.
