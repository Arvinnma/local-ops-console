# Local Ops 使用手册

## 1. 资源类型

- **托管服务**：Local Ops 通过 Process Compose 负责启动命令和进程生命周期。
- **SSH 隧道**：连接 SSH 主机，并把本机回环端口转发到远端目标。
- **现有服务**：只探测可用性，不负责启动、停止或重复接管。
- **本地域名**：由 Caddy 把 `*.localhost` 域名转发到本机回环端口。
- **终端操作**：保存后在 Terminal.app 或 iTerm2 中执行的命令、SSH 登录或 SSH 转发。

## 2. 总览与“需要关注”

总览显示托管进程、现有服务、本地域名和异常数量。点击“需要关注”可以展开完整清单，逐项看到停止、健康检查失败或离线原因，并跳转到对应页面。该数量不仅包含 Local Ops 托管的进程，也包含“现有服务”中的离线项目。

## 3. 添加服务

进入“服务”，选择“添加资源 → Node / 命令服务”。显示名称、唯一 ID、工作目录和启动命令为必填项；健康检查、重启策略、自动启动、分组、图标和本地域名为可选项。

```text
工作目录：/Users/you/Projects/order-api
启动命令：npm run dev
健康检查：http://127.0.0.1:3000/health
本地域名：api.localhost
服务端口：3000
```

列表左侧主按钮用于开启或关闭；编辑、重启、日志和删除在右侧“更多”菜单中。使用“排序”列的拖动手柄调整顺序，界面会立即移动，再异步保存到本机配置。

## 4. 添加 SSH 隧道

下面的命令：

```bash
ssh -NT \
  -o IdentitiesOnly=yes \
  -o ExitOnForwardFailure=yes \
  -o ServerAliveInterval=30 \
  -o ServerAliveCountMax=3 \
  -i ~/.ssh/example_vps \
  -L 127.0.0.1:3000:127.0.0.1:3000 \
  deploy@203.0.113.10
```

对应填写：SSH 用户 `deploy`、SSH 主机 `203.0.113.10`（文档专用示例地址）、本地端口 `3000`、远端主机 `127.0.0.1`、远端端口 `3000`。Local Ops 会自动加入 `-NT`、`IdentitiesOnly`、`ExitOnForwardFailure` 和断线保活参数。

卡片会分开显示：

```text
经由 deploy@203.0.113.10
本地监听 127.0.0.1:3000 → 转发目标 127.0.0.1:3000
```

## 5. 现有服务与反向代理

“现有服务”来自配置中的健康检查目标。例如 `HCB Index` 可以只监控 `127.0.0.1:4173`，即使这个 Vite 进程由其他工具启动。Local Ops 不会因此重复启动它。

本地域名必须以 `.localhost` 结尾，转发目标必须是 `127.0.0.1:端口` 或 `localhost:端口`。未启用无端口访问时，地址会带 `:19080`；启用后可省略端口。

无端口访问通过 macOS PF 把回环 80 端口转发到 Caddy。首次启用或修复时需要管理员授权，浏览器页面无法请求这项系统权限，必须在 App 内操作。

## 6. Docker

Docker Engine 未运行时可以点击“启动 Docker Desktop”。若开启“启动 App 时开启 Docker 和所有容器”，Local Ops 会先打开 Docker Desktop，等待 Engine 就绪，再启动全部已停止容器。Local Ops 不会创建、删除或导出容器。

## 7. 终端操作

可以保存普通命令、仅登录 SSH 或 SSH 本地转发，并选择系统 Terminal 或 iTerm2。第一次执行时 macOS 可能询问是否允许 Local Ops 控制所选终端。

## 8. 启动自动化

以下开关默认全部关闭：

- 登录 macOS 后自动打开 Local Ops。
- 打开 App 时启动全部尚未运行的自定义服务。
- 打开 App 时连接全部尚未运行的 SSH 隧道。
- 打开 Docker Desktop，等待 Engine，然后启动全部已停止容器。

## 9. 配置导入与导出

导出包含服务、SSH 隧道、现有服务、反向代理、终端操作、界面语言和非 Docker 启动设置。不会包含 Docker Engine、容器、Docker 启动偏好、本机 API 密钥、SSH 私钥内容、系统端口和管理员授权。

导入会替换上述可迁移资源，因此导入前建议先导出备份。旧版本中不含语言字段的配置仍然可以导入，并保留当前语言。

## 10. 常见问题

- **服务一启动就停止**：打开“更多 → 日志”，检查工作目录和启动命令。
- **健康检查异常**：确认 URL 指向真实监听地址，并返回成功 HTTP 状态码。
- **SSH 隧道失败**：先在终端测试 SSH 主机和私钥，再检查本地端口是否被占用。
- **本地域名打不开**：确认 Caddy 和目标服务在线；省略端口时还要确认无端口访问已启用。
- **Docker 不可用**：安装或启动 Docker Desktop，并等待 Engine 完成启动。
- **界面状态未更新**：点击刷新，或进入“设置 → 重新加载全部配置”。

日志默认位于 `~/.local/share/local-ops/runtime`。
